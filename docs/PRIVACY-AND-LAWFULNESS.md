# Privacy and Lawfulness Boundaries

Public accessibility is not proof of lawful access, permitted reuse, accuracy or absence of personal data. Source terms, licenses, jurisdiction, privacy rules, access restrictions and retention must be reviewed for the actual purpose and operator.

## Initial prohibitions

- No private-person targeting or identity resolution.
- No profiling, doxxing, stalking, harassment or mass surveillance.
- No collection of sensitive personal data, credentials, authentication material or private records.
- No circumvention of access controls, paywalls, rate limits, robots restrictions or provider controls.
- No authenticated collection in this initial scaffold.
- No source content storage or personal data in public fixtures.

## Required review

Before any future collection adapter is enabled, a qualified reviewer must confirm source terms and license, legal basis/purpose, privacy impact, data minimization, access conditions, retention/deletion, user rights, security controls and jurisdictional obligations. The compliance register is monitoring metadata only and does not provide legal advice.

## Data minimization

Prefer metadata fields, narrow target namespaces, small record/byte ceilings and short retention. If the source may contain personal or sensitive data, deny by default and require a separately reviewed use case. The current planner permits only sources declared public and non-personal.
